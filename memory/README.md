# Second brain

Claude searches this folder before designing any study (CLAUDE.md rule 1). Plain Markdown, one file per thing.

- `scales/` – one file per validated instrument (copy `scales/_TEMPLATE.md`). Fill in only from real sources.
- `briefs/` – every research brief and its results (`YYYY-MM-DD-<slug>.md`, copy `briefs/_TEMPLATE.md`).
- `heuristics/` – fraud checks, decision-rule conventions, rubrics.
- `2ndbrain/` – optional link to your personal notes:
  `ln -s ~/path/to/2ndbrain memory/2ndbrain` (the link is git-ignored, so your notes never get pushed).
